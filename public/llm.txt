# BuiltWhileBroke (BWB)

> BuiltWhileBroke is a curated suite of 34+ world-class, 100% client-side open source workbenches and developer utilities that run entirely in the browser with zero cloud tracking, zero cookies, and zero server roundtrips.

## Core Architecture & Privacy Principles
- **100% Client-Side Computation**: All processing (PostgreSQL WASM queries, SQLite compilation, AI object removal, cryptographic AES-256 PBKDF2 hashing, PDF generation, regex evaluation) executes inside browser memory.
- **Zero Telemetry & Zero Cookies**: No analytics cookies, no tracking pixels, no server-side payload logs.
- **Permissive Open Source**: Curated and built upon top-tier open source projects (MIT, Apache-2.0, LGPL-3.0, BSD-3-Clause, AGPL-3.0).
